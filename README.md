## 🚀 Featured Projects

### 🦀 omniroute-model-importer
Rust CLI for bulk-registering models to a self-hosted OmniRoute instance from a JSON config.
- Idempotent diffing: detects changes before applying, so no duplicate registrations
- `--dry-run` flag to preview operations without side effects
- Modular design: config parser, API client, diff engine, reporting
- Replaced one-by-one dashboard entry for 30+ models

### 🐉 D&D Character Manager (CLI/TUI)
Cross-platform character sheet manager inspired by D&D Beyond, written in Rust.
- Phase 1 done: CLI MVP with import/export, stat calculations, inventory tracking
- Phase 2 in progress: native desktop + mobile from a single codebase
- Stack: Rust, Ratatui, Axum
- Public beta available, feedback from the D&D community is welcome!

### 📰 News API
REST API with JWT authentication, role-based access control, and CRUD for users and content.
- Stack: Rust, Actix Web, Diesel ORM, PostgreSQL
